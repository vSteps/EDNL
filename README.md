# EDNL — Estruturas de Dados Não Lineares

Repositório de estudos da disciplina de **Estruturas de Dados Não Lineares**. Aqui você encontra anotações, exercícios e implementações desenvolvidos durante a matéria.

## 📚 Sobre

O objetivo é organizar os conteúdos da disciplina e praticar estruturas que representam relações mais complexas entre os dados.

## 🗂️ Conteúdo

- **Anotações** — conceitos e resumos das aulas
- **Exercícios** — práticas para fixar o conteúdo
- **Implementações** — estruturas e algoritmos em código
- **Projetos** — trabalhos desenvolvidos na matéria

> O conteúdo será atualizado conforme a disciplina avançar.
